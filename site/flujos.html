sin salir de la terminal.

Dos formas de trabajar, el mismo principio: todo queda guardado donde corresponde. Cierras Kali, vuelves otro día y la investigación sigue ahí.

URB Red · laboratorio

Cinco pasos, un laboratorio.

Dentro de RED los comandos cortos funcionan sin prefijo. Fuera, antepón urb red.

01

Crea el laboratorio

lab new htb-lame --target 10.10.10.3

Estructura de carpetas y objetivo persistente en un solo paso.

02

Reconoce

recon initial

Progreso real de nmap. Si falla, conserva el log y lo diagnostica.

03

Inventaría

services

Puertos y versiones desde los XML de nmap, con historial por escaneo.

04

Documenta

findings add "FTP anonymous"

Hipótesis, estados, notas fechadas y evidencias vinculadas.

05

Entrega

report generate

Informe Markdown en reports/, sin sobrescribir tu report.md.

Diagnóstico honesto

Distingue lo que sabe
de lo que sospecha.

Cuando nmap falla, URB solo lee lo que ya produjo la ejecución: no lanza pings, consultas ni reintentos.

confirmed

Lo ha dicho nmap o el sistema

Por ejemplo: no se puede resolver el nombre, hacen falta permisos de root o la red no es alcanzable.

possible

Una hipótesis, no comprobada

«Host seems down» no demuestra que el host esté apagado: puede filtrar el ping o la VPN puede estar caída.

unknown

Causa no reconocida

Lo dice tal cual y te indica dónde está el log para que lo revises tú.

Estado de un hallazgoSignificado
pendingPendiente de revisar.
investigatingEn curso.
suspectedHipótesis: hay indicios, pero no está verificada.
confirmedVerificado con evidencia. Confirmado no significa vulnerabilidad.
discardedHipótesis comprobada y refutada.
checkedComprobación realizada sin hallazgo.

URB Blue · investigación

De un CSV a un caso cerrado.

Todo ocurre en tu máquina, en un workspace propio con base SQLite. Sin servicios externos.

01

Crea el workspace

workspace new incident-rdp

Base de datos y copias privadas de fuentes y evidencias.

02

Ingiere

ingest windows security.csv --tz +01:00

CSV de Windows o auth.log, con procedencia por SHA-256 y sin duplicados.

03

Detecta

detect run --threshold 5 --window 600

Fallos 4625 agrupados por IP en ventanas móviles.

04

Tría

alerts status A-001 investigating

Las alertas son coincidencias, no ataques confirmados.

05

Investiga

cases link C-001 --alert A-001

Casos con notas, evidencias, historial y cierre.
