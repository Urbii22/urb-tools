Command Engine

Comandos cortos y combinables

Los modificadores van en cualquier orden, usan el objetivo del laboratorio y rechazan combinaciones imposibles con un mensaje claro. Con --dry-run ves el nmap exacto sin ejecutar nada.

urb red recon quickversions --dry-run
→ nmap -T4 --open --top-ports 100 -sV 10.10.10.3

Referencia rápida

Cada módulo,
también como comando.

El manual completo está en la propia terminal: urb manual.

MóduloQué haceEjemplo
RECONNmap con perfiles configurables: quick, default, full, stealth, udp y os.urb scan 10.10.10.5 --profile quick
NETWORKInterfaces, rutas, gateway, conexiones, descubrimiento de hosts, ping y chequeo.urb network discover 192.168.56.0/24
MONITORCPU, RAM, swap, discos y procesos; ordena por CPU o memoria.urb monitor procs -n 15
LOGSAutenticación, SSH, errores y búsqueda por fecha, usuario, IP o texto.urb logs ssh --user root -n 50
CTFCrea laboratorios con scans/, exploits/, evidence/, notes/ y report.md.urb ctf new htb-lame --target 10.10.10.3
SERVEServidor HTTP local, en 127.0.0.1 por defecto.urb serve --port 8080
SETTINGSVer y editar la configuración, animaciones y motor de menús.urb config set ANIMATIONS 0
DOCTORComprueba dependencias y entorno.urb doctor
